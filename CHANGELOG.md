# Changelog

What this fork adds on top of Aegis Authenticator 3.4.3. The Aegis vault format stays readable.

## 3.5.3-idroot

- Release builds no longer contain the git branch name, so a build from a tag matches a build from master.

## 3.5.2-idroot

- Privacy policy and terms of use open inside the app. They do not need a network connection.
- Those texts now cover short notes.

## 3.5.1-idroot

- The About screen names Sebastian Fleckenstein. The original Aegis authors stay listed.

## 3.5.0-idroot

- Secure notes in the same encrypted vault, for short secrets such as Wi-Fi passwords.
- Notes export and import are separate from authenticator codes. A code export contains no notes.
- Copying a code with under 4 seconds left copies the next code. The switch sits next to Show next code.

## 3.4.3-idroot

- Rebrand to IDroot Authenticator, package `org.idroot.authenticator`, own signing key.
- IDroot colors, icon, and name. Not affiliated with Beem Development.
